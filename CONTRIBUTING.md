# Contributing to Agentic Vault

First off, thank you for considering contributing to Agentic Vault! It's people like you that make open-source software such a great community.

## How Can I Contribute?

### 1. Reporting Bugs
If you find a bug, please create a new issue on GitHub. Include:
- Your operating system (Windows, macOS, Linux).
- Your Obsidian version.
- Steps to reproduce the bug.
- Any error messages from the Developer Console (`Ctrl+Shift+I`).

### 2. Suggesting Enhancements
Have an idea to make Agentic Vault better? We'd love to hear it! Open an issue with the `enhancement` label and describe your idea in detail.

### 3. Pull Requests
If you want to contribute code:
1. Fork the repository.
2. Create a new branch (`git checkout -b feature/amazing-feature`).
3. Make your changes.
4. Test your changes locally in your Obsidian vault.
5. Commit your changes using Conventional Commits (`feat: ...`, `fix: ...`).
6. Push to the branch (`git push origin feature/amazing-feature`).
7. Open a Pull Request.

## Development Setup
1. Clone your fork locally.
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start compiling changes automatically.
4. Copy the compiled `main.js`, `manifest.json`, and `styles.css` into a test Obsidian vault to preview your changes.

Thanks for helping make Agentic Vault better!
