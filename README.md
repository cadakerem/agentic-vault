# Agentic Vault

> An Obsidian plugin for Git-backed AI configuration, automated vault synchronization, and pattern-based secret scanning.

[![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)

## ⚡ Features
- **Auto Git Sync**: Background auto-pull, commit, and push.
- **Secret Scanning**: Pre-commit scanning to prevent leaking API keys.
- **Brain Manager**: A dedicated visual editor to manage your AI System Prompts and Rules.

## 🏗️ Architecture & Under the Hood
- **Language**: TypeScript
- **Libraries**: obsidian-api, simple-git
- **Design Pattern**: Modular agentic architecture with robust error handling.

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/cadakerem/agentic-vault.git
cd agentic-vault

# Install requirements
npm install
```

## 💻 Usage

```bash
# Example command
npm install && npm run build
```
