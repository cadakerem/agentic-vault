# Changelog

## [2.4.1] - 2026-10-02

### Fixed
- **Gemini Hardlink Path:** Fixed a typo where the target hardlink for Gemini was erroneously named Rules.md instead of GEMINI.md.


## [2.4.0] - 2026-10-02

### Added
- **Direct Hardlink Architecture:** AI tool configs (`~/.claude/CLAUDE.md`, etc.) are now hardlinked directly from the Vault Master Rule, rather than tracking entire tool directories inside the vault. This keeps your vault clean from cache files, conversation histories, and temporary tokens generated by AI tools.
- **Strict Release Verification:** Release workflow now validates `package.json` and `versions.json` against the release tag.
- **Included Paths Overrides:** `includedSyncPaths` are now explicitly pushed to `.gitignore` as whitelist rules and forcibly added via `git add --force`, fixing the issue where explicitly included paths were ignored by default-deny rules.

### Fixed
- **Path Traversal Security Fix:** Added strict containment checks (`path.resolve` relative checks) to prevent `.md` rules or folder settings from breaking out of the Vault directory (`../`).
- **Conflict Backup Collision:** Backup refs for conflicts now use millisecond precision and a randomized string to prevent Git ref collisions when multiple conflicts happen within the same second.
- **Removed Directory Symlinks for AI Tools:** To support the new Direct Hardlink Architecture, the Setup Wizard no longer symlinks the entire `~/.claude` or `~/.gemini/config` directories to the vault.



All notable changes to this project will be documented in this file.

## [2.2.0] - 2026-10-02
### Added
- **3-File Architecture (Zero-Conflict)**: Separated plugin configuration into three distinct files to eliminate sync conflicts and device state loss:
  1. `data.json` (Tracked & Synced): Pure UI configuration and global settings (e.g., aiTools, gitAutoPush). Safe to sync across multiple machines.
  2. `local-state.json` (Ignored): Device-specific volatile state like `deviceName`, `syncState.lastOkAt`, and `paused`. Prevents infinite Git conflicts when multiple devices sync simultaneously.
  3. `secrets.json` (Ignored): API keys.
### Fixed
- Removed tracking exceptions for `data.json`, ensuring global settings sync consistently without causing unstaged change errors or silent device state deletions during Git pulls.
- Implemented `--autostash` across all rebase operations, ensuring the plugin won't crash even if a tracked file is manually excluded via `excludedPaths`.

## [2.1.8] - 2026-10-02

## [2.1.7] - 2026-10-02
### Fixed
- **Sync Stabilization:** Fixed an issue where the plugin's auto-sync would fail with "cannot pull with rebase: You have unstaged changes" because data.json was hardcoded to be excluded from git add.
- **Gitignore Generation:** Changed ensureGitignore to append .obsidian/* instead of .obsidian/. This prevents the plugin from accidentally overriding users' manual un-ignores (like !.obsidian/plugins/) and resolves the "Ignored files are still tracked" error.
- Updated automated tests to assert the exclusion of secrets.json instead of data.json.
